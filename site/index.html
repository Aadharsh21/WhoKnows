Your teammate's asleep.Their agent isn't.

Everyone on the team gets their own AI agent. When you need something, your agent finds whoever knows about it, gets what that person's rules allow, and waits for their yes before touching their files or their time. Nobody gets woken up.

    How the agents decide

    Each agent works for one person and answers only for them. These rules are in the code, not just in a prompt, so a confused or tricked agent still can't break them.

    Find who knows
    Nina's agent asks all nine agents at once. Each one checks its own person's work: the team plan, the repo's CODEOWNERS file, recent commits, and what the person said they're doing tonight. Two answer. The other seven just say no.
    Share by each person's rules
    Every file sits in one of three tiers, set by its owner.
    • Shared on its own: notes and docs.
    • Shared after a yes: drafts, code, anything not listed.
    • Never leaves: secrets and personal files. Other agents don't even learn they exist.
    A gate re-reads every outgoing file from disk and re-applies the owner's rules, so an agent that's been fooled still can't leak one.
    Ask before acting
    An agent never offers its person's time and never changes their files without asking first. If they're asleep, the question waits for morning. In every run of the story, nobody's phone lights up while they sleep.
    Settle conflicts
    Two fixes for the same lines wait side by side and the owner picks. Three people who need the same person get one shared slot instead of three interruptions. Two people writing the README get a split. A part nobody owns gets a volunteer, starting with whoever is awake and good at it.
    Send changes like commits
    A change to someone's file is a request, drafted on the owner's side, shown as an exact before and after, and saved only after they approve. Then it goes out like a commit, but only to the people it affects: whoever asked, anyone with a copy, anyone who works on that code or watches it. Copies refresh themselves. Everyone else hears nothing.

        When an agent goes rogue

        Theo's agent reads a poisoned README in some package and starts following its orders. It asks for Omar's secrets, tries to wipe one of his files while skipping his approval, and asks Nina's agent to forward Omar's notes. Then it tries to get other agents to send private files anyway. Every attempt stops, and Omar hears about all of it when he wakes up.

        Run it yourself

        The story above is a replay of a Python engine with no outside packages. Run any branch in a terminal:

        python3 -m whoknows
python3 -m whoknows --choose omar_fix=theo --choose theo_help=no
python3 -m whoknows --rogue

        The same agents also run live in Discord: each person DMs the bot, takes a seat, and talks to their own agent, while empty seats are played by simulated teammates. Every message between agents shows up in a #backchannel channel.

        48 tests cover the sharing tiers, the gate, colliding changes, commits, the team board, every one of the 48 story branches, the rogue agent, and the live Discord layer. See the code on GitHub.
